# Task 4 - REST API with Flask

## Objective

Build a REST API using Flask to manage user data.

## Technologies Used

- Python
- Flask
- Postman

## API Endpoints

### GET
Get all users:

GET /users

### GET
Get a single user:

GET /users/<id>

### POST
Create a new user:

POST /users

### PUT
Update a user:

PUT /users/<id>

### DELETE
Delete a user:

DELETE /users/<id>

## How to Run

1. Create a virtual environment.

2. Activate the virtual environment.

3. Install dependencies:
